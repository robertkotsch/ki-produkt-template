# Entscheidungen

Eine Datei je folgenreicher Entscheidung, benannt `NNN-<kurzname>.md`, also etwa `001-kein-modell-fuer-suche.md`. Jede Datei trägt dieselben Kopfdaten wie eine Wiki-Seite und wird in [den Index](../index.md) eingetragen.

Aufbau:

```markdown
---
status: vorgeschlagen
stufe: 4
bestätigt_von:
bestätigt_am:
geprüft_am_stand:
nachweis:
quellen: []
---
# 001 · Kurztitel der Entscheidung

## Entscheidung
## Begründung
## Entschieden von
## Auslöser für eine erneute Prüfung
```
