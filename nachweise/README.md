# Nachweise

Eine Datei je ausgeführter Prüfung, benannt `JJJJ-MM-TT-<kurzname>.md`. Ein Nachweis hält fest, was am benannten Stand tatsächlich beobachtet wurde. Erst mit einem Nachweis darf eine Wiki-Seite den Status `geprüft` erhalten.

Jeder Nachweis enthält:

- Version oder Commit des geprüften Stands
- Voraussetzungen
- Eingabe
- Befehl oder Bedienfolge
- erwartetes und beobachtetes Ergebnis
- bei Modelltests zusätzlich Modellkennung, Einstellungen, Prompt- und Datenstand sowie das Bewertungsverfahren
